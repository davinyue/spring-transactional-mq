# 代码风格检查脚本适配

## 背景

现有代码风格检查脚本沿用了 voucher-bridge 项目的包名、模块路径和 DDD 分层约束，无法正确检查当前事务消息组件。

## 目标

使脚本默认检查当前项目全部生产 Java 源码，并仅保留通用且与项目匹配的检查规则。

## 范围

- 修改 `scripts/check_code_style.py` 的项目根包、默认扫描路径与提示信息。
- 移除原项目的 DDD 分层和技术选型检查。

## 非目标

- 不新增第三方静态检查工具。

## 关键设计

默认扫描所有 `spring-transactional-mq-*` 模块的 `src/main/java` 目录；保留编码、换行、Java 8、导入、JavaDoc 与泛型相关规范（实例化使用菱形操作符、调用方法不显式指定类型参数）等通用检查，不再根据领域、应用、接口或 DTO 分层施加规则。针对脚本反馈，逐文件修复泛型写法、CRLF 换行和 JavaDoc 问题，避免批量替换造成语义错误。

## 验收标准

- 默认扫描路径覆盖所有项目模块的生产 Java 源码。
- 项目源码包名校验使用 `org.rdlinux.transactionalmq`。
- 脚本中不存在 voucher-bridge 或 DDD 分层检查。
- 脚本可通过 Python 语法校验并正常执行。
