# 消费后回调异常测试适配

## 背景

消费后回调已调整为接收消费处理异常，现有测试未验证成功和失败场景下的异常参数传递。

## 目标

补齐 API、RabbitMQ 和 Kafka 的回调异常参数断言。

## 范围

- 验证 `QueueMsgHandleRet` 将异常传递给回调。
- 验证两种 MQ 监听器在成功时传递 `null`，在回滚失败时传递异常。

## 非目标

- 不修改生产代码和消费处理流程。

## 关键设计

复用现有监听器成功与业务回滚测试，在消费者返回值中注册 `FinallyCall` 并断言其收到的参数。

## 验收标准

- API 层能验证回调收到传入异常。
- RabbitMQ 和 Kafka 的成功、回滚场景均验证回调参数。
- 相关模块测试通过。
